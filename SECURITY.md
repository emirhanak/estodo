# Security policy

Please do not report security vulnerabilities through public GitHub issues.
Send a concise description and reproduction steps to
**flashemirhan@gmail.com**. Do not include real user task content, passwords,
tokens, signing keys, or other personal data in reports.

The public repository intentionally excludes production Firebase
configuration, signing material, and store credentials. Contributors should use
their own Firebase project and the example configuration under `config/`.
